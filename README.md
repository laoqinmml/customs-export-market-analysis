# 海关出口市场分析

这是一个 Codex Skill，用于根据中国海关年度 CSV 导出数据分析出口市场，并整理成 Markdown 指南。它适合已经拿到海关数据、希望比较不同国家市场的外贸从业者。

## 开始前准备

请提供以下材料：

- 产品名称，以及已核实的 8 位 HS 编码。
- 一份或多份海关年度 CSV 导出文件。
- 需要更新的 Markdown 指南（如果已有）。
- 希望纳入分析的市场经验、利润门槛或重点地区（可选）。

如果 HS 编码还没有核实，Skill 会提醒你先确认商品名称、适用范围、申报要素和编码有效性；它不会只凭产品名称替你定码。

## Skill 会做什么

1. 检查 CSV 字段、字符编码、HS 编码和贸易伙伴数据。
2. 过滤目标 HS 编码，检查重复记录，并规范出口金额。
3. 判断各文件的统计期间和年度数据是否可以比较。
4. 计算出口总额、市场变化和国家趋势，说明数据限制及异常情况。
5. 根据实际数据和经营条件比较候选市场，并创建或更新 Markdown 指南。

分析会区分海关数据事实与市场建议。宽泛 HS 类目的出口额不会直接当作某个细分产品的市场需求。

## 工作边界

- 海关网站的查询、参数设置和 CSV 导出由用户手动完成。
- Skill 不登录或操作海关网站，也不提供网站操作教程。
- 年度、币制、统计月份或贸易伙伴范围无法从文件确认时，会标注口径不明；必要时请你补充信息。
- Skill 不会为追求退税率而建议使用与实际商品不符的编码。

## 安装

将本仓库中的 `customs-export-market-analysis` 文件夹复制到 Codex Skills 目录下，例如：

```text
~/.agents/skills/customs-export-market-analysis/
```

确认 `SKILL.md` 位于该目录根部，然后在 Codex 中使用与海关 CSV、HS 编码出口数据或国家市场比较相关的请求。详细行为规则见 [SKILL.md](SKILL.md)。
